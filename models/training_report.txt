Deployed model trained on the 'temporal' split.

EVALUATION METHOD
  Two accuracies are reported for every model.

  Split: samples are split per class by TIME -- earliest 80% train, latest
    20% test. A random split is optimistic here because the collector records
    many near-identical consecutive frames while a key is held, and a random
    split puts near-duplicates of the test rows into the training set. The
    random-split figure is printed alongside for comparison.

  Label accuracy:  did the classifier name the right gesture?
  Action accuracy: would the system have taken the right action? Labels that
    trigger the same action are not a user-visible error when confused.
    Labels sharing one action: NEUTRAL, OPEN_PALM
