Gesture-Controlled Presentation System - Dynamic Swipe Training Report
Dataset: D:\college\S3\Projects\gesture-presentation-control (CLD)\data\dynamic_gesture_data.csv  (230 clips recorded, 8 features)
Random Forest size: 50 trees
Deployed model trained on the 'temporal' split.

CLEANING (applied before any split)
  30 clip(s) dropped: net sideways travel contradicted their own label
    (the hand's return motion was captured inside the fixed recording window).
  27 swipe clip(s) dropped: |dx| < 0.1, too small to
    distinguish from a still hand.
  173 clips remain.

AUGMENTATION (training split only)
  Mirroring (a left swipe is the mirror of a right swipe) and speed-scaling
  by (1.5, 2.0, 2.5) (the same motion performed faster/wider).
  Ratio features (straightness, direction_consistency) are scale-invariant and
  left untouched. Test clips are real recorded clips only -- never augmented.

EVALUATION METHOD
  Two accuracies are reported for every model.

  Split: samples are split per class by TIME -- earliest 80% train, latest
    20% test. A random split is optimistic here because the collector records
    many near-identical consecutive frames while a key is held, and a random
    split puts near-duplicates of the test rows into the training set. The
    random-split figure is printed alongside for comparison.

  Label accuracy:  did the classifier name the right gesture?
  Action accuracy: would the system have taken the right action? Labels that
    trigger the same action are not a user-visible error when confused.
    (every label triggers a different action, so the two figures match)
